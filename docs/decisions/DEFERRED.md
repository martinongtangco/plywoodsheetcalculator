# Deferred Decisions

These items were discussed during V1 design and deliberately deferred. They do not block V1 development. Each item has a tracking issue.

| # | Item | Why Deferred | Target Version |
|---|------|-------------|----------------|
| OQ-1 | Back panel mount type (recessed / face-mounted / offset) | Recessed assumed as default. V2 adds per-box toggle. | V2 |
| OQ-2 | Toe kick notched into side panels | Breaks rectangular part assumption. Needs L-shape part support. | V2 |
| OQ-3 | Adjustable shelf pin hole patterns | Out of scope for a sheet calculator. | V2 |
| OQ-4 | Drawer face dimension auto-calculation from overlay type | UX design needs more work. V1 allows manual input. | V2 |
| OQ-5 | Undermount slide base position modelling | Complex variance. V1 uses user-specified base_offset. | V2 |
| OQ-6 | Cloud sync and user accounts | V1 is localStorage only. | V2 |
| OQ-7 | 3D cabinet preview | V1 is 2D only. | V2 |
| OQ-8 | Mixed sheet sizes per material (offcut reuse) | V1: one sheet size per material. | V2 |
| OQ-9 | Offcut reuse across projects | V1 outputs offcut inventory but does not consume it. | V2 |
| OQ-10 | Face frame / inset door cabinet style | V1 is frameless (European) only. | V2 |
